Stream Frame Helper is not installed

The start page lives in the helper extension, which Chrome has not loaded in this profile.

  1. Over SSH, re-run ~/.local/share/stream-frame/install.sh (or the copy you installed from), then relaunch Stream Frame.
  2. If Chrome shows a “New extension added” notice, choose Enable extension.
  3. Still missing? Open chrome://extensions, turn on Developer mode, click Load unpacked and pick ~/.local/share/stream-frame/extension.

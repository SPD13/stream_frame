# S6: Controller events in the panel

**Status:** not run · **Date:**

## Steps

1. Launch Stream Frame, gear icon → Controls. The *Receiving* indicator shows every key and
   gamepad button the page gets, and whether it is in gamepad or keyboard mode.
2. Press every controller button under: the default layout for a non-Steam shortcut, Steam's
   "Gamepad" template, and the "Keyboard and Mouse" template. Record what arrives.
3. On Netflix and Disney+ during playback, press A (play/pause) and the d-pad (seek): does the
   player respond? (Netflix goes through `extension/bridge-netflix.js`, others through
   `video.play()`/`pause()`/`currentTime` in `extension/actions.js`.)
4. Try shipping a layout: copy a layout into Steam's `controller_config` folder for the shortcut's
   app id, or call `SteamClient.Input` over the DevTools port. Does Steam pick it up?
5. Does a gamepad button press count as user activation for fullscreen on each service?

# S1: Chrome + DRM baseline

**Status:** not run · **Date:** · **SteamOS / Chrome versions:**

## Steps

1. Over SSH: `flatpak install --user flathub com.google.Chrome` (or `./install.sh --no-shortcut`).
2. Launch Chrome from the KDE desktop panel. Open `chrome://components` and confirm
   *Widevine Content Decryption Module* is present with an arm64 version.
3. For each service, play a title for 2 minutes and record the maximum resolution
   (Netflix: `Ctrl+Alt+Shift+D`; YouTube: *Stats for nerds*; others: the player's quality menu or
   `chrome://media-internals` → video decoder resolution).
4. Repeat Netflix with the "New Netflix 1080p" extension (`mdlbikciddolbenfkgggdegphnhmnfcg`).
5. Repeat every service with `--user-agent` set to the ChromeOS string in `lib/config.env.example`.
6. 30 min of 1080p Netflix: note CPU (`top`) and battery drop (`upower -d` or the Steam UI).

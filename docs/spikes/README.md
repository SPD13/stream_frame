# Phase 0 spikes

On-device checks from `docs/plan.md` (Phase 0). Each file is a worksheet: run the steps on the
Steam Frame, fill in the results, and set **Status** to `GO`, `NO-GO` or `GO with changes`.
The code in this repository already implements the plan's defaults; each spike lists which
file or setting to change if the result differs.

| Spike | Question | Status |
|---|---|---|
| [S1](S1.md) | Chrome + Widevine plays the seven services; resolution caps | not run |
| [S2](S2.md) | Chrome from a Steam shortcut becomes its own panel; Theater + passthrough | not run |
| [S3](S3.md) | Can the panel go above 1280×720? | not run |
| [S4](S4.md) | Silent extension install, seeded profile, fullscreen, Home overlay, login persistence | not run |
| [S5](S5.md) | Does SteamVR remember the panel's dock state? | not run |
| [S6](S6.md) | What controller events reach the page? Can a layout be shipped? | not run |
